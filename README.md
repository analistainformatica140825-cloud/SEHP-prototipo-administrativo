# Servicios Especiales de Hojalatería y Pintura

Sitio público y prototipo administrativo integrados en un solo sitio.

## Publicación desde el navegador
1. Descomprime este ZIP.
2. En el repositorio de tu sitio, usa Add file > Upload files.
3. Arrastra el CONTENIDO de la carpeta descomprimida: index.html, css, js, img y administracion. No subas el ZIP ni una carpeta exterior.
4. Guarda con Commit changes.
5. Settings > Pages: Deploy from a branch, main, / (root), Save.
6. Espera la publicación y comparte la URL de Visit site.

## Uso
Desde la página principal pulsa Acceso administrativo en el pie de página (también está el icono de candado). Desde el panel puedes regresar al sitio público.

Acceso de demostración: usuario admin; contraseña taller2026.
Es una validación de demostración en JavaScript, no autenticación segura para operación real.
Los registros se guardan en localStorage del navegador: no se comparten entre equipos ni se guardan en GitHub. Utiliza las opciones de respaldo del panel para conservarlos. Usa datos ficticios en la demostración pública.

Los recursos externos (tipografías, iconos y enlaces a WhatsApp) requieren conexión a Internet.
